# Data

Not committed (large and/or third-party). Drop your files here; everything except
this README is git-ignored.

| file | made by | what it is |
|------|---------|------------|
| `S&P 500 Historical Components & Changes (Updated).csv` | external | `date, tickers` — point-in-time index membership (e.g. [fja05680/sp500](https://github.com/fja05680/sp500)) |
| `short_vol.parquet` | `Notebooks/build_dataset.ipynb` | FINRA daily short-volume ratios |
| `short_int.parquet` | same | bi-monthly short interest, PIT-aligned |
| `fundamentals.parquet` | same | SEC fundamentals, filing-date aligned |
| `md_raw_long.parquet` | same | raw downloaded price panel, long format |

The FINRA/SEC pulls are slow and rate-limited — fetch once, reload forever.

## `interim/` — stage-to-stage handoffs

The split notebooks (2–5, see `Notebooks/README.md`) pass work through here. All
git-ignored; regenerated by re-running the stage that produces them.

| file | made by | what it is |
|------|---------|------------|
| `model_df.parquet` | `build_model_df.ipynb` | finalized point-in-time modelling panel |
| `pipeline_meta.json` | same | feature lists, hypotheses, horizon/annualisation constants |
| `pred_df.parquet` | `walkforward_models.ipynb` | per-name walk-forward OOS predictions + forward returns |
| `best_params.json` | same | tuned Ridge/Lasso/ElasticNet hyperparameters |
| `portfolio_returns.parquet` | `portfolio_sizing.ipynb` | per-period return series for L2 / L4 / L5 / net |
